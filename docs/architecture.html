Catalyst Components — System Architecture

Factory inventory management demo: a Vue 3 single-page app talking to a FastAPI service that serves in-memory data loaded from JSON files. No database.

System overview

Tech stack

Frontend

  • Vue 3, Composition API
  • vue-router 4 (6 routes)
  • axios for HTTP
  • Vite dev server, port 3000
  • i18n: English, Japanese

Backend

  • Python, FastAPI, uvicorn
  • Pydantic models for validation
  • uv for dependencies
  • Port 8001, Swagger at /docs

Data

  • 7 JSON files in server/data/
  • Loaded once into memory
  • Filtering happens in Python per request
  • No persistence, no database

Tooling

  • pytest + TestClient in tests/backend
  • Claude Code agents, commands, hooks, skills in .claude/
  • MCP: Playwright, GitHub (.mcp.json)

Data flow — a filtered request

  1. The user changes a filter in FilterBar (Time Period, Location, Category, Order Status).
  2. useFilters updates shared reactive state; the active view re-runs its loader.
  3. src/api.js sends GET /api/…?warehouse=…&category=…&status=…&month=….
  4. FastAPI runs apply_filters / filter_by_month over the in-memory lists.
  5. Results are validated against Pydantic models and returned as JSON.
  6. The view stores raw data in refs; KPIs, charts and tables are computed properties over those refs.
